# Original design assets

The repository stores the original binary files losslessly in `assets/part-*.json`. Run `pnpm assets` to restore them to `public/`; development and production builds do this automatically. Every file is verified using its SHA-256 checksum. This packaging preserves the original bytes rather than substituting new imagery.

`public/original/` contains assets exported from the user's read-only Illustrator documents: 老人高保真2.ai, 护工高保真cc.ai and 家人高保真cc.ai. The photographs, fine-art works, gallery interiors, sculpture, plant cutouts, logo and wordmark are the embedded originals. The mood gauge, mood collection, senior avatar and four category icons are rendered directly from the original vector artwork. They were not redrawn or generated.

The provided design uses Gilroy, Garet, Britannic Bold and Bernard MT Condensed. Local installed font files were used to preserve those typefaces.

The prior stock art photograph is no longer used. Exhibition content uses the user's supplied Monet paintings, marble sculpture, original gallery rooms and artwork collection.

Audio is a locally synthesized ambient sound study. Original recordings for the named collection songs were not supplied, and the player states this explicitly.
